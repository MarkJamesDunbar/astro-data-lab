TESS Starhunter

A phased roadmap for a homebrew Linux box that ingests photometric survey data including TESS, Kepler, and K2, and learns to classify stars (hopefully). It's also a testbed for a handful of technologies, approaches, and workflows that add up to a complete ML lab - one I'd like anyone to be able to pick up and use. The only AI-generated part of this repo is this page (it looked cool, and I'm lazy) (and maybe some UI work later too, i am bad at that stuff)

Read this alongside Phase 0

While you're getting comfortable with the tool, start on these - they'll shape the problem statement you write in Phase 1. Search titles/authors on arXiv or NASA ADS yourself.

YearPaperWhy it's on the list
2018 Shallue & Vanderburg"Identifying Exoplanets with Deep Learning" (AstroNet) The original global+local phase-folded CNN approach almost everyone since has riffed on.
2019 Yu et al.AstroNet-Triage Adapts the AstroNet idea to TESS full-frame-image scale triage - the closest existing relative of this project.
2022 Valizadegan et al.ExoMiner Ensemble CNN currently used to help vet real TESS Objects of Interest - a good architecture to study, not necessarily to copy.
2022 Malik et al.Machine learning survey for exoplanet detection Covers feature-based / classical-ML approaches - useful if you want a non-deep-learning baseline first.
